## How to use this page

1. Answer each question on paper **before** looking at the key.
2. Mark each attempt: ✅ correct, 🤔 guessed (even if right), ❌ wrong, ⏭️ skipped.
3. Review guesses as carefully as misses.
4. Questions S3-Q26 to S3-Q30 are saved for the final weekend. Do not open them early.

All questions are original practice, not real test questions. Unless a question says otherwise, use **1 mL = 1 cm³**.
